Format untuk penghubung data

Penghubung harus membaca semua riwayat ruang DEPOSIT DIBANTU 1X, termasuk halaman lama, lalu mengembalikan JSON berikut. userId harus ID member dalam isi pesan, bukan nama pengirim/admin. Setiap pesan pada sumber ini berarti ID tersebut sudah dibantu.

{
  "room": "DEPOSIT DIBANTU 1X",
  "next": null,
  "complete": true,
  "messages": [
    {"text": "contohuser >> https://sleekshot.app/v/CONTOH", "timestamp": "2026-09-22T09:00:00+07:00"}
  ]
}

Setiap pesan boleh berisi banyak baris. Hanya baris ID >> link Sleekshot yang diambil. Sebagai alternatif messages, sumber boleh mengirim text berisi seluruh teks chat. Link Sleekshot adalah halaman bukti, sehingga ditampilkan sebagai tombol buka bukti; bukan dipaksakan menjadi gambar langsung. Untuk riwayat bertahap, next berisi URL halaman berikutnya pada sumber yang sama. Dashboard membaca semua halaman sebelum menggabungkan data. Halaman terakhir memakai next: null; complete: true hanya jika sumber telah memeriksa seluruh riwayat ruang. Ini contoh format, bukan data asli. Respons harus HTTP 200 dengan Content-Type application/json. Untuk HTML dari origin lain, API perlu mengizinkan CORS dan sesi cookie dengan credentials. Jangan menaruh password/token rahasia dalam HTML. Waktu memakai ISO 8601 dengan zona waktu. Pesan tanpa waktu ditampilkan sebagai tidak tersedia.

Catatan disimpan pada browser/perangkat ini. Cadangkan JSON untuk pindah perangkat. Dashboard menandai status; tidak memblokir tombol deposit pada sistem admin.

Gambar tidak dapat dimuat. Sesi login atau tautan gambar mungkin sudah berakhir.
